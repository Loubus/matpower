# Combined exploratory A+B experiment

This copy composes the analytic physical-current equation and activation metadata from Experiment A with Experiment B's augmented limit-transition corrector and transported incoming tangent. It is a third, explicitly combined experiment rather than a replacement for either isolated comparison. No production or historical file is edited.

`exc_cpf.m` was generated by applying A's equation-activation changes to the exact saved `continuation_limit/b17_cpf.m` implementation; `source_hashes.json` records source hashes. The per-file diff `experiment.diff` compares the CPF copy against that B source, and the PF copy against production. `exc_transition_journal` is a uniquely named copy of B's logger. The output from the reused generator script saying "unchanged fixed-lambda transition correction" describes A's base generator and is **not applicable to this combined CPF source**: the combined file retains B's `b17_transition_corrector` for converter and generator transitions.

The original saved study inputs and all options are retained except the separately requested 0.05 step-size sensitivity. The 200-step budget is retained. Current-limited rows have no release implementation and reject a second current/voltage/dispatch intersection outside the supported state. Any repeated/discrete-event, recovery or physical-control incompatibility must be audited before calling a trace valid FULL continuation. Numerical success does not certify a physical maximum.
