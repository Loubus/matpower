# AB2: coupled converter limit plus transported tangent across every active-set change

This is a separately saved follow-up to `combined/`, not a replacement. It retains that experiment's current-limit equality, analytical derivative and augmented converter/generator transition corrector. It changes one continuation decision: initialize the carried direction at every trial from the last accepted tangent and its physical state identities. The existing identity mapping and dot-product orientation then also apply to tap/shunt-only changes, instead of falling back to a positive-lambda natural tangent.

The existing augmented capability transition may replace that carried direction with its locally computed incoming-plane direction. On retries the loop starts again from the restored accepted case/context and tangent, so a rejected trial's carried vector is not reused. All bus/state dimensions are mapped by the B implementation's physical state keys; newly introduced coordinates start at zero in the orientation seed and are solved in the new tangent system. `journal` logs each active-set outgoing direction, orientation dot product and mapped/new state counts.

There is no new capability-release heuristic, equipment parameter, tolerance change or iteration-budget extension. Each run retains 200 continuation steps and the original requested FULL endpoint. The original 0.1 step and 0.05 sensitivity are saved separately. `all_controls.diff` records the exact incremental change relative to the first combined experiment. Production code and previous results remain unchanged.
